# AquaGuard AI — India-wide interactive prototype

## Run
1. Extract this ZIP to a new folder.
2. Open `AquaGuardAI.csproj` in Visual Studio 2022.
3. Ensure the **ASP.NET and web development** workload and .NET 8 SDK are installed.
4. Press Ctrl+F5.

## Included pages
Overview, India-wide interactive risk map, water monitoring, rule-based risk prediction lab, disease intelligence, alert centre, reports studio, and awareness hub.

## Map
Leaflet + OpenStreetMap tiles. The map contains illustrative demo markers across multiple Indian states. Use search and risk filters; click markers to update the details panel. Internet is required for map tiles and CDN-hosted chart libraries.

## Data and safety
All locations, sample readings, counts and alerts are synthetic demonstration data. The prediction page uses a transparent rule-based scoring example, not trained AI/ML, a validated outbreak forecast, laboratory testing or medical diagnosis. Do not use it for real public-health decisions.
